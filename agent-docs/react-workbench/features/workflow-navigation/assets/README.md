# Workflow navigation reference assets

[`workflow-header.png`](workflow-header.png) was moved without changing image bytes
from the Automatic Timing & Review package on 2026-11-18. It illustrates a top
workflow header with project/version identity and global actions. Labels, version,
spacing and completion badges are examples, not implementation requirements.

[The feature spec](../SPEC.md) owns navigation decisions. The related
[Timing HTML prototype](../../automatic-timing-review/assets/timing-workflow.html)
remains in its original package as a cross-feature reference; it is simulated and
must not become a second app or an implicit part of Timing implementation.
