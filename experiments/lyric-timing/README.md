# Lyric timing experiments

Local generated outputs live in Git-ignored `artifacts/`:

- `samples/medium/` and `samples/turbo/`: owner-supplied 35-second word-timestamp runs.
- `full-medium/`: full-song Whisper transcript/subtitles, `comparison.json`, and
  `line-proposals.csv` with 36 occurrence-level timing suggestions.
- `reports/`: preserved comparisons from earlier evaluation runs. Some original
  inputs were replaced by the owner; these reports are historical results.
- `reference-song.json`: extracted authored song data used for these comparisons.

Source audio remains in `public/Macchiato_Special_Affection_for_You.mp4`.
Extracted temporary WAV files need not be retained because they can be regenerated.
Generated suggestions have not been applied to authored timings.

See [evaluation notes](../../agent-docs/react-workbench/ASSISTED_TIMING.md)
for methods, results, limitations, and remaining acceptance gates.

## Keep Walking held-out run

`artifacts/keep-walking-medium/` contains the owner's full medium-model transcript,
extracted reference, `comparison.json`, character-baseline `line-proposals.csv`,
and two historical audition review files (the audition UI has been removed):

- `audition-characters.json`: exact character baseline.
- `audition-toneless.json`: tone-free dictionary Pinyin baseline, identified in
  the review's source label.

These retained review files have no lines marked reviewed. For current listening
checks, load a timed workbench project and matching MP4 in the Timing editor.

### Targeted inclusive-start listening experiment

`artifacts/keep-walking-medium/audition-toneless-inclusive-starts.json` recorded
including observed 铃鱼 in the eight supplied 淋雨一直走 chorus lines.
This copy advances those starts by 680–1220 ms relative to the tone-free baseline.
It also shortens line-11 and line-25 to the preceding observed phrase end:
Pinyin matching had incorrectly borrowed the following 铃 as their final 灵.
All other rows are identical to the baseline. A machine-readable before/after
list is in `inclusive-starts-changes.json`. The original audition files remain
unchanged. This is a targeted data experiment, not a general algorithm fix.

`audition-inclusive-starts-and-oh.json` builds on the inclusive chorus-start
experiment and also starts line-00 at the observed English Oh (10.88s instead
of the Chinese-only start at 12.88s). Its end and the other 71 rows are unchanged.
The original experiment files remain available for comparison.

### General boundary algorithm output

Keep Walking's `comparison-assigned.json` is regenerated by the general ordered
boundary-assignment mode. `audition-assigned.json` preserves the historical review.
It reproduces the accepted targeted starts and opening Oh without song-specific
rules; other changes and unresolved cases are listed in the evaluation notes.
Earlier experiment files are preserved unchanged. The local full cat-song lyrics
are now at `public/做你的猫.txt`; see the new-song evaluation below.

## New-song cat evaluation

`artifacts/cat-song-medium/` contains the owner's Whisper output and generated
artifacts using the full local lyrics at `public/做你的猫.txt` (not the planned synthetic
repository test fixture).

Load **`song.timed.workbench.json`** as a workbench project, select
`public/做你的猫 [rEV1VWwwAyA].mp4`, then open Timing. It has 72 automatically
assigned appearances out of 73; the final `line-72` remains unassigned because
its observed units cross a ten-second gap. These are editable automatic drafts,
not reviewed timings or translations.

Also retained: `song.workbench.json` (untimed dictionary draft),
`reference-song.json` (null reference times), `comparison.json`, `audition.json`,
`line-proposals.csv`, and `audio-info.json`. The historical audition review matches
both the timed and untimed project's ordered IDs/text, but is no longer loadable in the UI. No prior authored timing
reference existed for this song.

### Cat-song intro review copy

`artifacts/cat-song-medium/song.with-intro.workbench.json` is a retained review
artifact requiring the separate feature implementation: the committed schema
rejects its `detectedFromAudio` field. It is not a baseline-loadable project.
The six recognized opening lines span 2.96–18.40 seconds; the copy has 79
appearances (78 timed), preserving the original 73 appearances and their timings.
`intro-provenance.json` records the selected transcript segments. The owner approved
this copy. Earlier projects/reports remain available without these intro rows.
